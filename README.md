## 📁 Folder Structure

The workspace is organized chronologically by laboratory sessions. 

* **`lab1/`**, **`lab2/`**, **`lab3/`**... 
  Each directory corresponds to a specific class and contains the assignment for that week.

### Contents of each `lab[X]` directory:
* **Source Code:** Python scripts containing the implemented algorithms, logic, or games.
* **Screenshots:** Visual documentation of the working code, terminal outputs, and test results demonstrating the implementation.
