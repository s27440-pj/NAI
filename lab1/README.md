# Division Game 🧮

A simple mathematical game for two players (Human vs. AI) written in Python using the `easyAI` library.

## Game Rules
Given a starting number, players take turns dividing it by any of its proper divisors. The player who is left with the number 1 after their turn loses the game.

## Requirements
- Python 3.x
- `easyAI` library

## Installation
To install the required dependencies, open your terminal and run:
```bash
pip install easyAI
```

## Uruchomienie gry
Aby uruchomić grę wpisz w konsoli
```bash
python main.py
```
